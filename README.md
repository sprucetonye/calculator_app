Flutter Calculator App
🚀 Elevating User Experience with a Modern Flutter Calculator
Welcome to my Flutter Calculator project—a sleek, performant, and intuitive calculator application built with Flutter. This project showcases my ability to develop clean, maintainable, and responsive mobile applications while adhering to best practices in UI/UX design and state management.

🔥 Key Features
✅ Beautiful & Responsive UI – A modern, user-friendly interface with smooth animations and adaptive design for all screen sizes.

✅ Basic & Advanced Operations – Supports standard arithmetic (+, -, ×, ÷) as well as advanced functions (%, ±, clear all).

✅ State Management – Efficiently handles calculations using Provider or Riverpod (depending on implementation) for clean state management.

✅ Dark/Light Mode – Optional theme switching for better user preference customization.

✅ Cross-Platform – Works seamlessly on Android, iOS, and web thanks to Flutter’s versatility.

✅ Error Handling – Gracefully manages edge cases like division by zero and overflow errors.
